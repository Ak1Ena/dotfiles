How it looks inside Claude Code

A small mod reads the same signals the hooks already see and draws the current stage. Pick a moment in a task:

claude · ~/code/my-app
>

Three places it shows up

On by default

Stage band above the prompt

One line showing the stages, with the current one lit. It appears only while a task is moving, and is gone in plain Q&A.

On by default

Status line entry

QC state for the repo: lines not yet reviewed, guardrail PASS or BLOCK, and the gate's block count. Visible even when the band is off.

Open with /workflow

Side pane

Full checklist with times, each repo's diff size, the reviewer and guardrail results, and the open findings. Needs a terminal at least 110 columns wide.

With teammates (c-team)

Each teammate is its own Claude session in a tmux pane. Each one writes its stage to the team's shared folder, the same one the ledger uses. The lead reads them all, so you follow the whole team from the lead pane. Teammates skip the Stop gate. Their edits land in the lead's repo, so the lead's gate covers the team's whole change.

>

Where each stage comes from

Claude reports nothing by hand. Each stage is read from an event that is already happening, so the display cannot claim work that did not run.

StageLit whenDone when
Plan/goal or a pstack skill loads, or a task list is createdFirst file edit
BuildEdit or Write, by the main thread or a builder subagentA test, build or lint command runs
ProveBash runs a command matching test, build, lint or tscThe command exits; red if it failed

ReportThe turn ends and the Stop gate lets it throughNext prompt resets the band

Next step if this looks right

  1. Build the mod in ~/.claude/dev-mods/: band, status line, and the /workflow pane, reading the QC gate's state files so both agree.
  2. Claude Code asks once whether to turn on mods written in this session. Pick Turn them on to see it live.
  3. Each session writes its stage to the team folder; the lead mod reads the team rows from it, and the tmux status dots get a stage letter.
  4. Sync to dotfiles with the QC gate change.
