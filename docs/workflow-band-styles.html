Workflow band styles

Pick a band style. Each preview is what Claude Code will draw above your prompt, in four moments: building, QC blocked, passed, and with teammates. Previews use the same text, colors and boxes the plugin can draw.

Why color rail

Color rail keeps today's two-line layout and only adds color, so it needs no extra width, never wraps oddly in a narrow pane, and the red ✗ is the first thing you see when QC blocks.
